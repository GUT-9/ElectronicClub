# 前台与用户中心界面更新

本次仅修改前端，不增加数据库迁移、API、依赖或云函数代码。保留正式 Logo、蓝白配色、现有路由与全国大学生电子设计竞赛展示，以及已实现的登录、RBAC、活动报名签到、新闻、正文插图和论坛功能。

## 主要变化

- 首页活动与新闻使用真实封面卡片，缺少/加载失败的封面使用统一的品牌背景；单条内容使用横向展示，两条或多条自适应排列，不用虚构内容填补空白。
- 活动、新闻列表统一标题、搜索、结果数量与分页；加载中、空列表、搜索无结果、网络错误与重试独立展示，防止把加载失败误显示为“没有内容”。列表切换和搜索使用请求序号防止旧结果覆盖新页面。
- 活动详情增加时间、地点与状态摘要；读取报名状态失败时不会展示可误提交的报名表单，未开始、已截止或满额时禁用新报名按钮。最终资格和名额仍以原后端为准。
- 社区整理版块导航、列表工具栏、摘要、帖子状态与空列表提示；不在摘要中裸露媒体 ID。帖子、收藏、通知等使用各自的引导文案，并区分错误与真正的空列表。
- 用户中心增加常用入口，个人资料、成员档案和账号安全分区。默认不铺开 UID/原始时间等内部字段；身份资料仍只读，角色仍由后端控制。保留资料保存、修改密码、退出当前账号、退出所有设备与活动工作区。
- 登录页提供密码显示/隐藏、首次使用与重置说明、提交锁定；统一按钮、输入框、反馈样式及手机布局。
- 页脚保留服务诊断，将其放入可展开的“服务连接”，减少普通用户看到的调试感。无障碍跳转、键盘焦点和减少动画偏好继续可用。

## 部署与回退

推送 main 后，EdgeOne 使用原项目配置重新构建前端即可。无需执行新的 SQL 或重新上传 CloudBase ZIP；此前 011 图片功能所要求的后端版本仍应保留。API 地址和 Cookie/跨域配置不变。

如需回退，只回退本次前端提交，不回滚数据库或成员数据，也不替换已经工作的云函数版本。根目录 `deployment-packages` 的现有 ZIP 保持不变。

## 验证范围

`npm ci` 完成，标准 `npm run check` 检查包含 SQL 一致性、ESLint、TypeScript、现有业务测试与生产构建。本机 Chromium 使用明确的模拟数据检查首页、活动、新闻、社区、详情、登录及用户中心在 375/1440 宽度下的布局、图片有无两种情况；覆盖登录与密码显隐、资料保存、成员/安全分区、退出、社区空列表、摘要图片引用过滤、搜索清除、网络错误重试及报名截止的按钮状态。没有横向页面溢出或未捕获的页面异常。浏览器模拟验证不等于生产部署验收，没有写入生产账号或业务数据。

最终结果：53 项业务测试通过，0 失败、0 跳过；ESLint、TypeScript 与生产构建通过。当前 `npm audit --omit=dev` 报告 3 项 moderate、0 high/critical；本次没有修改依赖或锁文件。
