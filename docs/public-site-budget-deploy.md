# 公开读取不触库与每月1500点预算

使用现有七牛公有空间提供公开内容副本，保留CloudBase PostgreSQL、成员密码、RBAC、报名签到和论坛写入。浏览器仍只访问同源 `/api`，不新增付费服务、第二套认证或定时保活。

**状态：源码、增量SQL、完整ZIP和本地测试已准备，不代表已执行生产迁移或上传函数。1500点为条件性预算目标；缺少共享实例单价和实际动态活跃时段时，不宣称已实测达标。**

## 当前CloudBase与EdgeOne操作顺序

1. CloudBase PostgreSQL SQL编辑器执行 [016-public-site-export.sql](../cloudbase/sql/016-public-site-export.sql)，再执行只读 [016-public-site-export-verify.sql](../cloudbase/sql/016-public-site-export-verify.sql)。需已完成015及之前迁移，不重跑初始化。016只增加受限导出函数和版本记录，不清空表、不改密码、不创建角色。
2. 核对 [完整ZIP](../deployment-packages/electronicclub-api.zip) 的 [SHA256](../deployment-packages/electronicclub-api.zip.sha256)，替换现有 `electronicclub-api` 代码。入口 `index.main`，函数超时设为 **60秒**，内存可保持256MB。原网关、Cookie、Origin、数据库和代理签名设置保留。
3. 在 **CloudBase → electronicclub-api → 环境变量**保留原 `QINIU_ACCESS_KEY`、`QINIU_SECRET_KEY`、`QINIU_BUCKET`、`QINIU_DOWNLOAD_DOMAIN`，新增 `PUBLIC_SITE_ORIGIN`，暂不启用qiniu模式。填实际桶的HTTPS S3外网源地址，不含路径或末尾 `/`。此前截图对应 `https://edwell-k12.s3.cn-east-1.qiniucs.com`；实际桶/区域如有不同，以七牛控制台为准。本地未验证生产源能否读取。
4. **EdgeOne部署最新main**，包含根目录 `edge-functions`，保留原构建设置。首次先不在EdgeOne填 `PUBLIC_SITE_ORIGIN`，让尚未生成副本的公开页继续可用。
5. 超级管理员打开官网 **`/admin/public-site` → 同步公开内容**。等待“已同步”、待同步图片为0。首次图片较多时可多次同步，会继续已保存进度。七牛专用目录为 `electronicclub/public-site/v1/`。不重新导入成员或初始化管理员。
6. **CloudBase函数环境变量设置 `PUBLIC_SITE_MODE=qiniu`** 并生效。公开读取改走七牛，缺失或故障明确报错，不自动查库。
7. 建议在 **EdgeOne项目的服务端环境变量**也填 `PUBLIC_SITE_ORIGIN`，值与第3步相同，再部署一次。此项进一步让公开请求跳过CloudBase函数。未填时公开请求仍通过函数读七牛，同样不查PostgreSQL。**七牛Key只留CloudBase，不放EdgeOne或任何VITE变量。**

可选：核实共享实例每核秒单价后，在CloudBase设置 `PG_POINTS_PER_CORE_SECOND` 给预算表预填。未知留空，后台显示无法判定，不会默认达标。

首次导出仍需数据库和云函数可用。如果环境已经因额度耗尽停服，需要先恢复可用额度或等待下一周期，才能完成首次同步；本次优化不会返还历史已消耗点数。

## 1500点预算条件

本地已验证500次公开请求和保留登录Cookie的浏览器刷新8类公开页面，均不调用数据库。EdgeOne填写公开源后，普通内容和图片也不调用CloudBase函数；需时间校验的公告及其独立图片经函数解密但不查库，计入函数预算。七牛的存储、请求和流量使用已有账户额度，不等于无限免费。

登录、主动打开个人状态、发帖评论/点赞、报名签到、后台管理、SQL编辑器和维护脚本仍可触发计算时段。保留实时会话和权限验证，**不会在1500点时突然停用成员功能**。

`月度预计点数 = 动态活跃5分钟段数 × 150核秒 × 已核实的每核秒单价 + 其他资源预留`

默认目标1500点，先给函数、存储和流量预留300点，数据库预算1200点。以下为敏感性示例，不是实际共享单价：

| 假设每段扣点 | 数据库预算内最多段数/月 | 活跃覆盖时间/月 |
| --- | --- | --- |
| 10点 | 120段 | 10小时 |
| 15点 | 80段 | 6小时40分钟 |
| 20点 | 60段 | 5小时 |

**只有真实每段单价不超过15点、每月动态活跃不超过80段、其他资源不超过300点时，预计合计才不超过1500点。** 20天、每天覆盖20分钟为80段。分散操作要把不同5分钟段全部计入，不能填写SQL运行的毫秒数。后台预算表可以按真实单价计算允许段数，未知单价时不显示达标结论。

用户截图只确认150核秒，并无点数换算价格。上线后仍需实际CU明细核对；若动态操作超过预算条件，公开读取改造不能保证整站总额。没有购买套餐、迁移数据库或改变登录权限来强行达标。

## 功能与安全

- 首页、活动/新闻列表详情、公开论坛版块/帖子/评论、定时弹窗、资料目录/下载入口和已公开图片从副本读取。搜索、分页、公告时间选择不查库。存储异常或陌生搜索词不会触发SQL回源。
- 公开页不自动恢复会话或读取个人报名、点赞、收藏。成员主动点击“查看我的报名、签到与管理入口”或“加载我的点赞、收藏与互动状态”后，沿用实时鉴权。纯静态浏览不自动写入成员浏览量；打开互动状态时继续防止同一成员24小时内重复计数。
- 本人待审核/隐藏帖子从“我的社区”进入实时成员预览；服务器继续校验本人/审核权限。编辑器的未发布图片用受鉴权的实时预览，游客不能读取。
- 业务保存后自动同步。失败会明确提示“内容已保存，公开页面尚未同步”，后台可重试，不会把七牛失败当作数据库未保存。配置CloudBase公开源后即会自动同步，便于启用前准备。
- 收藏、浏览计数、举报、成员导入、权限调整和普通签到等不改变公开内容的操作不触发全站副本重建。公开页统计显示最近发布副本的数值，成员自己的操作仍立即返回实时结果。
- SQL编辑器或绕过业务服务的CLI修改需要手动同步；没有新增常驻轮询或每分钟定时任务。
- 导出RPC仅现有受限后端角色可执行。以单条SQL读取一致的导出结果，发布时使用字段白名单。学号、手机号、邮箱、密码、会话、角色、报名名单、举报、审核原因、草稿和待审核内容不公开。正文保持安全文本渲染。
- 图片仅复制已公开绑定、上传完成且经真实格式检查的JPEG/PNG/WebP，最多50KiB。租约防止旧任务覆盖新版本，独立的小进度记录避免大型Base64 JSON再次触发413。中断或图片较多时可继续，不重复复制已完成图片。
- 文字和撤回信息优先更新；部分新图片未完成时显示待同步状态，再次重试。清单最多8MiB、SQL导出最多4MiB、最多640个公开图片引用/32MiB图片字节。超限明确报错，不静默截断帖子评论，原数据库内容保留。
- 只写入七牛专用前缀，拒绝覆盖其他资料对象。旧图片清理失败有记录并可重试，不删除数据库原图。已下载或第三方缓存的公开内容无法追收；副本用于公开内容，不作为私有资料权限控制。

预定弹窗及仅绑定弹窗的图片以AES-256-GCM加密保存为 `electronicclub/public-site/v1/timed.bin`，复用现有服务端七牛SecretKey派生密钥，无需额外配置新密钥。公开JSON不含预定标题、摘要或图片字节。EdgeOne没有解密密钥，这部分转到CloudBase函数按当前时间、目标发布状态校验后返回；图片未到发布时返回404，仍不访问数据库。密文篡改会被拒绝。轮换七牛SecretKey后应手动重新同步。静态公告切换模拟开始、到期和替换顺序，避免新公告到期后旧公告再次出现。

推荐S3源。如使用CDN域名，须保持有效HTTPS证书，并对site.json禁用缓存或控制到5秒且保留查询参数，避免旧清单。网站/API响应仍no-store；边缘不向七牛发送Cookie、Authorization或代理签名。生产网络、CDN和免费额度未在本地代验。

## 核对与回滚

- `/api/health`：`X-EClub-Data-Revision: public-site-budget-v1`；原网关修复版本头仍为gateway-body-v5。健康检查不查库。
- 公开接口应有 `X-EClub-Public-Delivery: qiniu-v1`；保存响应头 `X-EClub-Public-Sync` 为ready/pending/failed。
- 新增 `GET /api/public-site/config` 不查库；`GET /api/public-site/status`、`POST /api/public-site/rebuild` 仅超级管理员可用，重建写入现有审计，不硬编码职位。
- `category=database_window` 日志仅含应用数据库访问尝试的5分钟段和操作名，无正文、Key、Cookie或成员资料。**跨实例按window去重，不累计日志行数**；冷实例和失败连接可产生重复或未实际计费的采样，外部SQL操作不在其中，不能替代官方账单。
- 上线后按相同计费时区比较至少一天官方CU用量，再用实际单价和动态时段核算预算，不对生产循环压测。

回滚先删除EdgeOne的PUBLIC_SITE_ORIGIN并部署，再把CloudBase PUBLIC_SITE_MODE改为database；删除CloudBase PUBLIC_SITE_ORIGIN可停止自动同步。可恢复旧函数/前端，016增量函数保留，不删表、不恢复或重置成员/密码。清理副本只处理专用前缀。

本次为部署架构大改，按项目策略更新Linux/运维交付；仍不部署用户服务器、不切域名、不迁移生产数据库。完整本地测试与包校验见[当前交付记录](../deployment-packages/README.md)。
